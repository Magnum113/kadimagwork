# Рекламная кампания iPhone 18 — 05.ru

Адаптивная презентационная страница для коллег с основными параметрами рекламной кампании iPhone 18 на период 2 сентября — 1 ноября 2026 года.

Основной URL-раздел сайта: `/promo/iphone2026`.

Доступ к странице закрыт паролем. Пароль хранится только в серверной переменной окружения `PASSWORD`; после успешного входа браузер сохраняет защищённую cookie-сессию на 90 дней.

## Что находится на странице

- цели: 40 заявок; рост продаж компании на 16,6%; для интернет-магазина — продать 344 iPhone 18, получить около 44,9 млн ₽ выручки и 839 тыс. ₽ прибыли;
- этапы предзаказа и старта продаж;
- бюджет РСЯ 900 000 ₽;
- бизнес- и маркетинговые цели, целевые аудитории;
- CRM-календарь и SMS-сегменты;
- форматы и платные каналы по этапам;
- относительная динамика компании и отдельный абсолютный план интернет-магазина;
- ежедневный план-факт по заявкам, продажам, расходам и стоимости результата;
- метрики, источники и порядок отслеживания результата.

Внутренние задачи, статусы производства и рабочие блокеры остаются в документах кампании и на этой странице не показываются.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Переменная окружения

В Vercel добавьте переменную `PASSWORD` для нужных окружений — Production и, при необходимости, Preview. После добавления или изменения значения выполните повторный deployment. Сам пароль не добавляется в GitHub и не должен иметь префикс `NEXT_PUBLIC_`.

Для локального запуска создайте `.env.local` по примеру `.env.example`:

```bash
PASSWORD=ваш_пароль
```

При изменении пароля все ранее выданные сессии автоматически перестанут работать.
