# iPhone 18 — Campaign Control 05.ru

Адаптивная рабочая страница рекламной кампании iPhone 18 на период 2 сентября — 1 ноября 2026 года.

## Что находится на странице

- цели: 40 заявок на предзаказ и 3 850 продаж iPhone 18 net;
- roadmap предзаказа и старта продаж;
- бюджет РСЯ 900 000 ₽;
- стратегия и целевые аудитории;
- CRM-календарь и SMS-сегменты;
- матрица готовности форматов;
- план интернет-маркетинга;
- утверждённые тексты предзаказа;
- историческая база iPhone 14–17;
- scorecard план-факт и следующие задачи.

Данные зафиксированы на 1 сентября 2026 года. Неутверждённые значения не заменены предположениями: сайт прямо показывает, где ещё требуются медиаплан, методика или фактические данные.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Технологии

- Vinext / React 19;
- Tailwind CSS 4;
- shadcn UI;
- Lucide Icons;
- Cloudflare Worker-compatible build.
